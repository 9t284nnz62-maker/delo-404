Дело №404
Учебное веб-приложение на Python Flask - интерактивный детектив в браузере.
Идея проекта:
Игрок становится детективом и расследует вымышленное преступление: изучает материалы дела, собирает улики, читает переписки, опрашивает персонажей и выдвигает обвинение.
Интерфейс будет выполнен в виде рабочего стола детектива с доступом к телефону подозреваемого, почте, архиву документов и доске улик.
Планируемые возможности:
Регистрация и вход.
Выбор расследования.
Изучение улик, документов и переписок.
Опрос персонажей.
Сопоставление улик.
Выдвижение обвинения и просмотр результата.
Сохранение прогресса.
Технологии:
Python, Flask, SQLite, SQLAlchemy, HTML, CSS, JavaScript.
Первый этап:
Создать каркас приложения Flask, главную страницу и страницу первого дела с завязкой сюжета и одной уликой.
